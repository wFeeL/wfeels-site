# Контрольный список сделки

Редакция `0.2` от `2026-08-24`.

Для каждой сделки создаётся закрытая папка с номером Договора. В ней нет
паролей, полных карточных данных и лишних копий удостоверяющих документов.

## 1. До предложения

- [ ] Определён тип заказчика: организация, ИП, физлицо для бизнеса или
  физлицо-потребитель.
- [ ] Если заказчик — нынешний работодатель Исполнителя либо бывший
  работодатель менее двух лет назад, расчёт не планируется как доход НПД.
- [ ] Определено, кто принимает решение и подписывает документы.
- [ ] Зафиксированы цель, результат, ограничения, ориентир бюджета и срок.
- [ ] Не запрошены лишние персональные данные.
- [ ] Если нужны реальные данные третьих лиц, запланировано поручение обработки;
  до него используются синтетические данные.

## 2. Предложение и ТЗ

- [ ] Цена рассчитана по актуальному `PRICING.md`.
- [ ] ТЗ содержит закрытый перечень включённого и исключённого.
- [ ] Каждое обязательное требование имеет наблюдаемый критерий приёмки.
- [ ] Указаны материалы и решения, от которых зависит начало.
- [ ] Указано число раундов правок.
- [ ] Внешние расходы и владелец аккаунта определены.
- [ ] Этапы, суммы и сроки арифметически сходятся с общей ценой.
- [ ] Для цены ниже `70 000 ₽` установлен график 50/50 либо письменно выбран
  другой.
- [ ] Для цены от `70 000 ₽` установлены измеримые вехи.
- [ ] Указаны передаваемые исходники, инструкции и доступы.
- [ ] Разделены специально создаваемые, прежние и сторонние компоненты.
- [ ] Для каждого лично создаваемого охраняемого объекта указаны предмет
  авторского заказа и определимый срок создания.
- [ ] Для прежних модулей выбран режим лицензионного вознаграждения и перечислены
  нужные способы использования.
- [ ] Указаны привлечённые авторы, основания прав, открытые и существенно
  сгенерированные компоненты.

## 3. Договор

- [ ] Выбран подходящий шаблон B2B или B2C.
- [ ] ФИО, наименование, ИНН и полномочия подписанта проверены.
- [ ] Адреса и банковские реквизиты вставлены только в закрытый экземпляр.
- [ ] Определены согласованные email и аккаунты.
- [ ] Выбран способ подписания.
- [ ] При простой электронной подписи указаны закрытые адреса, точная фраза
  подписания, версия/идентификатор PDF и порядок хранения исходных сообщений.
- [ ] Договор и ТЗ имеют номер, дату и совпадающие стороны.
- [ ] Если есть реальные данные заказчика, подписано приложение о поручении.
- [ ] NDA подписано, если обычной оговорки о конфиденциальности недостаточно.
- [ ] Оба подписанных экземпляра сохранены в неизменяемом формате.

## 4. Перед первым платежом

- [ ] Статус НПД Исполнителя проверен на текущую дату через ФНС.
- [ ] Лимит НПД и допустимость вида дохода проверены.
- [ ] Получен корректный ИНН организации или ИП для чека.
- [ ] Счёт ссылается на Договор и конкретный Этап.
- [ ] Сумма и назначение совпадают с ТЗ.
- [ ] Для физлица персональный запрос «Запросить деньги» создан только для
  конкретной сделки; интернет-эквайринг не используется.
- [ ] Для организации или ИП подготовлены счёт и полные банковские реквизиты.
- [ ] Чек будет вручную сформирован через Т-Банк или «Мой налог».
- [ ] Заказчику известен канал получения чека.

## 5. После каждого платежа

- [ ] Сверены плательщик, сумма, дата и назначение.
- [ ] Чек НПД сформирован на полную сумму поступления.
- [ ] Для организации или ИП в чеке указан их ИНН.
- [ ] Наименование услуги совпадает с Договором и Этапом.
- [ ] Чек передан Заказчику.
- [ ] PDF или ссылка чека сохранены в закрытой папке сделки.
- [ ] Платёж внесён в реестр платежей и не продублирован.

## 6. Выполнение

- [ ] Работа начата после выполнения условий начала.
- [ ] Контрольные показы проведены по ТЗ.
- [ ] Решения Заказчика сохраняются с датой и отправителем.
- [ ] Новое пожелание не смешано с исправлением недостатка.
- [ ] Изменение объёма оформлено до выполнения.
- [ ] Секреты не попали в репозиторий, задачу, скриншот или внешний ИИ-сервис.
- [ ] Реальные данные используются только в разрешённой системе и объёме.

## 7. Сдача

- [ ] Проведены критерии приёмки.
- [ ] Передан полный комплект из ТЗ.
- [ ] Временные доступы переданы защищённо.
- [ ] Заказчику рекомендована смена паролей и включение MFA.
- [ ] Копии временных паролей, токенов, ключей и резервных кодов у Исполнителя
  удалены; лишний доступ отозван; доказательство передачи не содержит секрет.
- [ ] Передан перечень существенных сторонних компонентов и лицензий.
- [ ] Направлены акт и инструкция по проверке.
- [ ] Замечания связаны с конкретными пунктами ТЗ.
- [ ] Новые пожелания оформлены отдельно.
- [ ] Зафиксирована дата приёмки и начала 30-дневного периода исправлений.

## 8. Финальный платёж и права

- [ ] Финальная сумма соответствует ТЗ, изменениям и актам.
- [ ] Сформирован и передан финальный чек НПД.
- [ ] Выполнено условие перехода или предоставления интеллектуальных прав.
- [ ] Переданы исходники и доступы в согласованном объёме.
- [ ] Лишние рабочие доступы Исполнителя отозваны.
- [ ] Для логотипа и неперсональных материалов получено разрешение
  правообладателя либо кейс не публикуется.
- [ ] Для имени, должности, изображения, цитаты или отзыва физлица получено его
  отдельное согласие по статье 10.1 либо эти данные не публикуются.

## 9. Закрытие и хранение

- [ ] Папка содержит подписанные Договор, ТЗ, изменения и акты.
- [ ] Платежи сопоставлены с чеками.
- [ ] Удалены временные выгрузки и локальные копии реальных данных.
- [ ] Сроки хранения поставлены в календарь.
- [ ] Через 30 дней проверено завершение гарантийных обращений.
- [ ] Изменения инфраструктуры отражены в реестре ПД и уведомлении РКН.

## 10. Возврат или прекращение

- [ ] Получено письменное уведомление.
- [ ] Остановлена новая работа, кроме защиты данных и результата.
- [ ] Составлен расчёт полученного, выполненного, расходов и передачи.
- [ ] Для B2C не удерживаются произвольный штраф, упущенная выгода и
  безусловно невозвратный процент.
- [ ] Сумма и реквизиты возврата подтверждены без запроса CVC/CVV и кодов.
- [ ] Деньги возвращены прослеживаемым способом.
- [ ] Чек НПД скорректирован в соответствии с фактическим возвратом.
- [ ] Закрыта или изменена передача интеллектуальных прав.
- [ ] Данные и доступы удалены либо возвращены по документам.
