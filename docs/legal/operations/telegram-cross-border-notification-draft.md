## 2. Цель и основание

Цель передачи: оперативно доставить самому Оператору полную копию заявки,
которая до этого успешно записана в первичную базу на VPS в Российской
Федерации, для ответа заявителю и преддоговорного взаимодействия.

Основание обработки: конкретное информированное согласие заявителя,
подтверждаемое отдельным пустым по умолчанию чекбоксом; после начала переговоров
также применяются действия по инициативе субъекта, направленные на заключение
договора. Согласие прямо сообщает о Telegram и трансграничном характере
доставки.

## 3. Субъекты и данные

- субъекты: посетители `wfeels.site`, самостоятельно отправляющие заявку;
- данные: имя или обращение, email или Telegram username, выбранная услуга,
  описание задачи, ориентир бюджета, URL страницы и случайный идентификатор
  заявки;
- не передаются: IP-адрес, значение honeypot, продолжительность заполнения,
  версии документов и отдельная запись доказательства согласия;
- специальные, биометрические данные, данные о судимости и паспортные данные
  формой не запрашиваются.

## 4. Техническая схема и срок

1. API принимает форму на VPS RUVDS в дата-центре RUcloud, г. Королёв.
2. SQLite-транзакция фиксирует заявку и доказательство согласия в РФ.
3. Только после успешной транзакции API вызывает `sendMessage` Telegram Bot API.
4. Сообщение доставляется в закрытый служебный чат Оператора.
5. `message_id` сохраняется отдельно от текста заявки.
6. Через 23 часа бот вызывает `deleteMessage`; это укладывается в
   опубликованное Telegram ограничение Bot API для удаления сообщений моложе
   48 часов.
7. В закрытом чате отдельно включён серверный auto-delete «1 день», который не
   зависит от доступности процесса на VPS.
8. При сбое доставки заявка остаётся в российской базе и повторяется без записи
   текста в журналы.

## 5. Иностранный получатель: подтверждённые сведения

Официальная Политика Telegram на `2026-08-24` называет контролёром Telegram
Messenger Inc. и сообщает о передаче внутри группы:

- Telegram Group Inc. — British Virgin Islands;
- Telegraph Inc. — British Virgin Islands;
- Telegram FZ-LLC — Dubai, United Arab Emirates.

Та же Политика сообщает, что cloud-chat сообщения хранятся на серверах в
зашифрованном виде, а ключи находятся в нескольких иных дата-центрах в разных
юрисдикциях; для пользователей, зарегистрировавшихся из UK/EEA, отдельно
названы дата-центры в Нидерландах. Для российского Bot API исчерпывающий список
государств хранения публично не назван.

## 6. Предварительная оценка по части 5 статьи 12

Подтверждено публичными документами Telegram:

- cloud-chat данные шифруются при хранении;
- ключи размещаются отдельно в нескольких юрисдикциях;
- Telegram описывает общий срок «не дольше необходимого для оказания сервиса»;
- предусмотрено удаление сообщений и аккаунта;
- Telegram заявляет внутренние стандартные договорные условия между компаниями
  группы и меры защиты целостности/конфиденциальности;
- бот удаляет копию через 23 часа, а таймер чата auto-delete — через один день.

Не подтверждено и не заменяется предположением:

- полный перечень государств, на территории которых обрабатывается сообщение
  Bot API, отправленное российским оператором;
- почтовый адрес, телефон и email Telegram Messenger Inc. для российского
  запроса по части 5 статьи 12;
- индивидуальное обязательство Telegram исполнять заданный Оператором срок 24
  часа за пределами доступного методу `deleteMessage` поведения;
- договор поручения обработки, заключённый между Оператором и Telegram.

## 7. Что переносить в официальную форму

Можно переносить без предположений: сведения Оператора, номер основного
уведомления, цель, основание, категории субъектов, перечень данных, дату оценки
`2026-08-24`, описание мер и подтверждённые юридические лица группы.

Поле «перечень иностранных государств» нельзя заполнять только по геолокации IP
`api.telegram.org`: сетевой адрес не доказывает место дальнейшего хранения.
British Virgin Islands и United Arab Emirates подтверждают юрисдикции компаний
группы, но публичная Политика прямо допускает иные дата-центры. Для документа с
юридической ценностью до подачи требуется получить у Telegram недостающие
сведения либо перейти на маршрут, при котором Telegram не получает открытый
текст персональных данных.
